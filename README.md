# MG7
## Devlog
My Tree of Birds script has the player gameobject, sparrows array, and interactiondistance variable. The player gamoebject and sparrows array is to get their position and use interaction distance to see if they are close enough to each other. Vecotr.distance was what I used so that I could take the player Vector3 postition and the birds vector3 postition and compare them. The array goes through each sparrow gameobject and activates each one if the player gets close enough.
